# Week 03 – SPY Return Analysis (2000–Present)

This project performs a basic exploratory analysis of SPY (S&P 500 ETF) using adjusted daily prices from Yahoo Finance.

## What is done

- Download adjusted prices via `yfinance`
- Compute daily returns
- Compute annual returns (end-of-year to end-of-year)
- Generate and save plots

## Key observations

- Annual returns are more frequently positive than negative.
- Negative years (e.g., 2008) can be more extreme than most positive years.
- Long-term trend remains positive despite occasional large drawdowns.

## Outputs

Figures are available in the `figures/` folder:
- Adjusted price over time
- Daily return distribution
- Annual returns bar chart
